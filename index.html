Roundrobin

the slow group letter - write when you're free, read a sealed issue, no feed
Experimental prototype. This page runs entirely on your device: no account, no server upload by this page. A letter travels only when a member deliberately exports the file and sends it in their own chat - there is no automatic delivery and no notification system here. Sealing an issue is a reading convention, not immutability: anyone holding the file can keep editing. Whatever members write travels inside the file, so pass it only to the group it belongs to.
